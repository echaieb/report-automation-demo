# Sales report automation

Paste CSV sales data and get an automatic management report: totals, best month/product, growth, chart and copy-ready text.

> Demo project (not production). All names, phone numbers and figures shown are fictional.

## Run
Open `index.html` in any browser. No build step or dependencies.

## Host for free (GitHub Pages)
Repository Settings → Pages → Deploy from branch → `main` / root.

## Stack
HTML, CSS, vanilla JavaScript. Arabic (RTL) interface, light/dark theme.
